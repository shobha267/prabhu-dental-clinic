# Prabhu Dental Clinic Website

Official website for **Prabhu Dental Clinic**, Center for Orthodontics, Periodontics & Implant Dentistry, located in Saraswathipuram, Mysore.

## About the Clinic
- **Specialists**: Dr. Mahesh H.V. (M.D.S. Periodontist & Implantologist) & Dr. Ramya K.S. (M.D.S. Orthodontist & Dentofacial Orthopaedist)
- **Legacy**: Serving patients with gentle, precision dental care since 2012.
- **Location**: Saraswathipuram, Mysore, Karnataka.

## Features
- **Responsive Modern Design**: Built with clean HTML5, CSS3, and JavaScript.
- **Bilingual Support**: English & Kannada language toggle.
- **Interactive Dental Mascots**: Subtle, slow-floating 3D character framing with mouse parallax.
- **Live Clinic Status**: Real-time open/closed status badge based on clinic working hours.
- **Appointment Booking & Inquiry**: Direct appointment modal and interactive WhatsApp integration.
- **Interactive Map & Clinic Tour**: High-resolution gallery and Google Maps directions.

## Local Development
To run this website locally:

```bash
# Start local server
npm run dev
```

Or open `index.html` in any modern web browser.
